Arrays:
-------
	What are arrays?
		Arrays are collection of similar(same) type(data type) store in contiguous location.
		
		If I want to store one or two values, then I can use normal variable.
		If you want to store like 100 values or more values of same type then go for arrays.		
		
		int arr[100]; //array declaration here data type is int
			//uninitialized array
			
		int arr[20] = {10, 20, 30 };//initialization
			//partially intialized array
			
		int arr[] = {10, 20, 30, 40, 50};
			//fully initialized array 
			
		int arr[];	//error 
			//You have to specify size or initialize
			

		
		//Here arr is created for storing 20 values, but initially stores only 3 values. Here size(20) is greater than assigned/initialized(3) values. In this case it is called as partial initialization.

		Advantage of arrays is that one name is given for storing multiple values.
		
			arr[0] --> first element/data is stored here 
			arr[1] --> second element/data is stored here 
			arr[2] --> third element/data is stored here 
			.
			.
			arr[99] --> Hundredth element/data 
			
			Here the numbers mentioned inside the square bracket is called index(position).

Character and Strings:
----------------------
	char str[100]; //char array 			
			

	'a' - 'z' --> 97 - 122
	'A' - 'Z' --> 65 - 90  --> 32 is difference 
	'0' - '9' --> 48 - 57
	
	'0' --> 48 --> 0011 0000
	'\0'--> 0  --> 0000 0000 --> Null character
	
	Strings in C, is represented as zero(NULL) terminated character array.
For Example:
-----------
	Remember partial initialization of arrays.
	
	char strOne[20] = "Hello how";
		In order for all string handling functions to work normally they are assumed to be terminated by null character.

How the compilation works in C/C++?
	In C, Compilation is done in 2 phases.	
		first.c  (program/ASCII text file)
			|
			| --> Pre-Processing 
			|
		first.i (source file/intermediate file)
			| 
			| --> Compilation (I Phase)
			|
		first.o (Object file )
			|
			|--> Linking (II Phase)
			|
		first.exe (Executable file)
		
		---> 
			first.s --> assembly code 
				is an intermediary step between intermediary file and object file.
				
Pre-Processing directive:
	Instruction to your pre-processor. Pre-processor  does very basic text processing, manipulation.
	
	All pre-processor instruction/directives start with # symbol. 
For example:	
	find the file with the given filename and include the contents of the file as part of my code.	
	
	#include <stdio.h>
		or 
	#include "stdio.h"
	
	#include <dir/file.h>
		or
	#include "dir/file.h"
		--> <> or "" 
			these symbol define where to start searching for the file to be included.
			
		<> --> default include directory --> /usr/include/
		"" --> first search your current working directory(CWD) if file does not exist then goto default include directory.

	#include <arpa/inet.h>
	
There are lots of other pre-processor directives: most commonly used are...
		#define 
		#ifdef
		#ifndef
		#else 
		#endif
		#if 

		#pragma
