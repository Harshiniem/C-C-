Bitwise Operators:

Have two variables num and pos:

	<<, & or >>, &, ?:	
Explaination:
-------------
	1. Check whether given bit position in the number is ON or OFF.
					   7654	3210	
		num --> 10 --> 0000 1010	
		pos --> 2
If 	num = 10, pos 2
Output:		
	2 pos in number 10 is OFF 

If	num = 10 and pos = 3
Output:		
	3 pos in number 10 is ON 
=============================================
num = 10, pos 2	
res = num & 1 << pos ;
0001 << 2  	--> 0100
10 --> num		---> 1010
1<<pos 			---> 0100  &
					------
					 0000 --> 0
		res ? "ON" : "OFF" --> OFF
==============================================
num = 10, pos 3	
res = num & 1 << pos ;
0001 << 3  	--> 1000
10 --> num		---> 1010
1<<pos 			---> 1000  &
					------
					 1000 --> 8 --> res 
		res ? "ON" : "OFF" --> ON		
---------------------------------------

===============================================
in Tradional Programming Languages we use counter variable to control the flow of the loop.
	1. variable to be initialized
	2. condition to be checked on the value of the variable
	3. alter the value.
while loop Syntax:	
-------------------
	cnt = 0; //initialization 
	while (cnt <= 10){ //condition checking 
		printf("%d  ", cnt);
		cnt++; //update or alter 
	}
	printf("\n");
	
do while syntax:
----------------
	cnt = 0 ;//initialization
	do {
		printf("%d  ", cnt);
		cnt++; //alter or update
	}while (cnt <= 10); //condition checking
	printf("\n");

for loop syntax:
----------------
	for (cnt=0; cnt<=10; cnt++)
		printf("%d  ", cnt);
	printf("\n");
