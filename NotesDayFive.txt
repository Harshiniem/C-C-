Function Overloading:
---------------------
	C++ is said to be a strong typed language. 
	
		void fun(int);
		void fun(char);
		void fun(float);
		void fun(double);
			Your compiler differentiates the differences in data types when coming to passing as arguments.
			
		Because C++ is strongly typed language, it is able to support function overloading.
		
		What is function overloading?
			two or more functions having same name with different signature.
			
		What is a function signature?
			name, number of arguments and the type of  arguments and the order in which these arguments are passed.
			
			Remember return type is not part of function signature.
			
			void fun(int, double);
			void fun(double, int);
			
		How is this achieved.(How is your able achieve this).
		
			Every C++ function name is internally mangled/changed/decorated so that user given name is different from the compiler generated name. 
			
			This name change is reflected in the object code (after compilation), so the linker does not throw an error of re-definition.
			
			This process of name changing is referred to name mangling in Linux and Name Decoration in Windows.
			
		Conflicts in function overloading:
		----------------------------------
		function with default args:
		---------------------------
		
			void fun(int =10);//in function prototype you can assign values to your argument list which we call default argument. 
			
			void fun(int a=10); //with argument name or no name

	C With Classes:
		The concept of Classes was introduced by Bjarne Stroustrup based on his understanding of a Simula. C++ is not the first Object-oriented Programming language. 
		
		There were other OOP languages like Algol, Simula.
		
		If a language is said to be an OOP language then it should support all the following 4 key principles.
		
		Key Principles
        	Abstraction
        	Encapsulation
			Inheritance
        	Polymorphism        	
	======================================================
	Abstraction(Implementation Hiding): 
		Abstraction means showing only the essentail features with clear boundary by hiding the implementation details.
		
	Encapsulation(Data Hiding):
		Encapsulation is the bundling of data and function that operator on that data into a single unit(Object). while restricting direct access to internal data(using private access specifier).
		
	Inheritance(Code re-use):
		Inheritance allows a class to inherit (derive) the features(data and functions) of an existing class (Base/Super/Parent). The newly created class is referred to as Derived/Sub/Child class.
		
		By Inheriting from an existing class, you tend to re-use the existing class.
		
		Inheritance provide a way of code re-usability by derivation.
		
	Polymorphism(Many Forms):
		Polymorphism allows the same interface (same name) to behave diffently depending on the object.
		
		When it comes to inheritance from OOP point of view, It is run-time polymorphism or function/method overriding.
		
		But for theoritical reasons,
			Indian authors use the term 
			
			Compile time polymorphism (using function overloading and operator overloading).
			
			Runtime polymorphism: function overriding using inheritance and virtual functions.
			
	There are other code re-usable 	terminology in addition to Inheritance, Composition and Aggregation.
	
	You have to understand:
		C++ is a superset of C. So whatever is supported in C will be supported in C++ as well. 
		
		In C, struct is used for creating a new data type by bringing different types of data types(which we call as members).
		
		struct Employee{
			int id;
			char name[25];
			double sal;
		};
		
		C is a procedure(function) oriented language. Where data is stored as separate variable and function which work on these data are passed as arguments. Here data and functions are separate.
		
		In C++, in order to provide backward compatibility C++ supports C syntax(i.e. struct). In addition to that C++ is an OOP language where it allows to combine both data and function together.
		
		struct Employee{
			private:
				int id;
				char name[25];
				double sal;
			public:
				void getDetails();
				void dispDetails();
        };
		
		or 
		
		class Employee{
        	private:
        		int id;
        		char name[25];
        		double sal;
        	public:
        		void getDetails();//function prototype
        		void dispDetails();
        };//blue print of an object
		
		Employee yuvaraj;//here yuvaraj is an object/variable of the class Employee.
		
		So the object is the one that is stored in the memory (real existence) where as class is just the skeleton structure or blue print to define them.
		
		Class is the unit for defining the object type. Once the class is defined, it can be used to create any number of objects.

		Constructor are special function in C++, which gets called when an object of a class is created.
	
		Why is Constructor a special function?
			1. It has to have same name as class name exactly.
			2. It does not have any return type, not even void.
			3. It gets called automatically, when an object of the class is created.
			
		1. Normal functions does not have any restriction on names given by the user.
		2. If a normal function does not return you have to mention void as its return type.
		3. You have explicitly called.
	
		Destructor:
		-----------
			Its is also a special function like constructors, its name should start with ~className.
			It gets called when an object(variable) goes out of scope.
